CSS Guide

如何快速生成现代 CSS 视觉效果

毛玻璃、柔和阴影和渐变背景是现代 UI 常见的视觉语言。关键不是参数越多越好，而是让效果和界面层级、背景、阅读性匹配。

毛玻璃效果怎么调

毛玻璃通常依赖 backdrop-filter: blur()。模糊值越大，背景越柔和；背景透明度越低，玻璃感越强，但文字可读性也更容易下降。

推荐起点：blur 8-16px，背景透明度 16%-30%，边框透明度 8%-18%。

阴影决定层级

卡片、弹窗和按钮都可以用阴影表达层级。轻量界面适合低透明度、大模糊的阴影；强调悬浮状态时，可以增加 Y 轴偏移和模糊半径。

  • 卡片阴影：柔和、面积大、透明度低。
  • 按钮阴影：面积小、颜色可跟随品牌色。
  • 弹窗阴影：更明显，但不要盖过内容本身。

渐变要克制

渐变适合用在主按钮、状态强调和品牌背景。大面积使用时，建议降低饱和度或减少颜色数量，避免页面显得廉价。

复制代码前检查

  1. 确认文字在背景上仍然清晰。
  2. 检查浅色和深色背景下的效果。
  3. 确认圆角、边框和阴影风格一致。
  4. 为 Safari 加上 -webkit-backdrop-filter。
