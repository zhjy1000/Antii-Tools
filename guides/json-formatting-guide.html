JSON Guide

JSON 格式化、压缩和校验怎么用

JSON 是接口调试、前端配置、日志分析里最常见的数据格式。把它格式化后，人能读；把它压缩后，机器传输更紧凑；先校验，则能避免一个小逗号拖慢半天排查。

格式化适合什么时候用

接口返回、浏览器存储、配置文件和埋点日志通常是一长串文本。格式化会缩进对象和数组，让层级关系更清楚，适合阅读、排错和分享片段。

压缩适合什么时候用

压缩会移除多余空格和换行，适合放到请求参数、环境变量或较小的配置字段里。压缩不会改变数据内容，但可读性会下降。

常见 JSON 错误

  • 属性名没有使用双引号。
  • 数组或对象最后多了一个逗号。
  • 字符串里包含未转义的换行或引号。
  • 把 JavaScript 对象写法误当成 JSON。

处理敏感数据要小心

调试真实接口时，JSON 里可能包含 token、手机号、邮箱、订单号等敏感信息。使用在线工具前，应确认工具是否会上传内容。Antii Tools 的 JSON 工具在浏览器端处理输入内容。
