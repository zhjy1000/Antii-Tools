About

为日常创作和开发准备的小工具箱

Antii Tools 是一个轻量的在线效率工具集合，面向前端开发者、设计师、运营和内容创作者。我们的目标很简单：把高频、琐碎、容易打断工作流的小任务做得更快、更直观。

我们正在解决什么

很多在线工具不是广告太重，就是流程太绕。Antii Tools 希望保持打开即用：压缩图片、生成二维码、调试 CSS 视觉效果，都尽量在一个清爽的界面里完成。

当前工具

  • 图片极客压缩：浏览器端压缩 JPG、PNG、WebP 图片。
  • 二维码工坊：生成可定制颜色、边距和纠错等级的二维码。
  • CSS 视觉神匠：可视化生成毛玻璃、阴影和渐变 CSS。
